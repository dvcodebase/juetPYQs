# juetPYQs Contributing 🧑🏻‍💻

## How to Contribute 

1. Fork this repository.
2. Upload PDF files only.
3. Follow the naming convention:

   SUBJECTCODE.Test_Num.Exam_Year.pdf
   Test_Num are 1, 2, 3 for T1, T2, T3
   Exam_Year: The year in which the examination was conducted.

   Examples:
   - 18B11CI411.1.2024.pdf
   - 18B11CI412.1.2022.pdf

4. Ensure:
   - PDF is readable.
   - File is not duplicated.
   - Subject code is correct.
   - Year is correct.

5. Commit your changes:

   git add .
   git commit -m "Add 18B11CI411 2024 PYQ"

6. Create a Pull Request.

## Pull Request Checklist 👈🏻

- [ ] PDF format
- [ ] Correct filename
- [ ] No duplicate file
- [ ] Correct subject code
- [ ] Correct Test_Num
- [ ] Correct year

Thank you for contributing to the PYQ Repository! 😎
